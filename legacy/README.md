# Legacy Connect4 Prototypes

This directory preserves the historical implementations and community contributions of Connect4:

- `legacy/v1_original/`: The flat-script prototype and early PR submissions before productionization into the modular `connect4` package.

All modern features, AI engines (Minimax, Heuristic, DP/MDP), and GUI/CLI interfaces are now structured under the top-level `connect4/` package.
